## 1. Pratiques à plus fort impact par type de page selon les organismes de recherche UX/e-commerce (Baymard, NN/g, Contentsquare…)

### Takeaway
Baymard reste la seule source publique donnant, par type de page, des critères observables assortis d'un « % de sites en échec » : en 2025-2026, 52 à 78 % des grands sites US/EU sont « mediocre or worse » selon la page (PDP 62 % mobile, checkout 59 %, navigation 61-65 %, listes produits 58 % desktop / 78 % mobile). Le checkout reste le levier chiffré le plus net (abandon moyen 70,22 % ; +35,26 % de conversion atteignable par le seul design ; 23,48 éléments de formulaire en moyenne contre 12-14 idéalement).

### Inferences
Critères testables dérivés (à transformer en lignes de grille ; la source du seuil est entre parenthèses) :
- **Homepage/nav** : (a) catégories produits au 1er niveau du menu mobile ; (b) ≤ ~10 sous-catégories par niveau ; (c) section courante surlignée dans le menu ; (d) méga-menu avec délai de survol 300-500 ms ; (e) aucun carrousel auto-rotatif sur mobile, pause au survol sur desktop ; (f) chaque produit visible dans une image lifestyle est cliquable ; (g) attributs partagés traités en filtres et non en catégories (Baymard navigation).
- **PLP** : (a) ≥ 3 visuels par produit accessibles depuis la liste ; (b) filtres prix/note/couleur/taille(capacité)/marque(gamme) présents ; (c) tris prix/note/meilleures ventes/nouveautés ; (d) récapitulatif des filtres actifs ; (e) variantes regroupées ; (f) prix à l'unité pour consommables (capsules, détartrants) (Baymard PLP).
- **PDP** : 8 must-have NN/g + (a) image « in scale » (cruciale pour cookware/machines : encombrement sur plan de travail) ; (b) coût total/livraison estimé près du CTA ; (c) lien politique de retour dans la zone d'achat ; (d) variantes en boutons ; (e) wishlist utilisable sans compte ; (f) réponses de la marque aux avis négatifs ; (g) galerie de photos clients navigable ; (h) prix à l'unité (Baymard PDP).
- **Panier/checkout** : (a) guest checkout = option la plus visible ; (b) création de compte proposée après confirmation ; (c) 12-14 éléments de formulaire max (7-8 champs) ; (d) date de livraison (pas « 48 h ») ; (e) coût total visible dès le panier ; (f) champs obligatoires et optionnels tous marqués ; (g) justification du téléphone ; (h) messages d'erreur adaptatifs ; (i) boutons +/- de quantité ; (j) règles de mot de passe minimales (Baymard checkout).
- Les 4 premières causes d'abandon chiffrées (coûts additionnels 40 %, délai 20 %, confiance 19 %, compte forcé 18 %) justifient une pondération plus forte de « transparence prix/livraison » et « confiance/paiement » que de l'esthétique.
- L'écart desktop/mobile de conversion (+74 %) combiné à 69,9 % de trafic mobile implique d'auditer en priorité sur mobile (Baymard note aussi le mobile systématiquement plus bas : 78 % d'échec PLP mobile vs 58 % desktop).

### Gaps
- Taux de support par type de requête de recherche interne, autocomplete, page « zéro résultat » : derrière le paywall Baymard Premium ; seul le chiffre agrégé 56 % [S] est disponible.
- Aucune donnée publique chiffrée récente trouvée sur les pages **compte client / self-service** et **post-achat** (suivi, retours) — Baymard a un volet « Accounts & Self-Service » mais non consulté ; NN/g payant.
- Date et taille de l'enquête Baymard sur les raisons d'abandon non indiquées sur la page (échantillon US).
- Rapport complet Contentsquare 2026 (rebond global, frustration/rage clicks, profondeur de session, chiffres par secteur) non accessible : il faut le Benchmark Explorer ([lien](https://csquad.contentsquare.com/benchmarks-explorer-2026)).
- CXL et Think with Google : aucune donnée 2024-2026 spécifique retenue pendant cette session (non recherchés faute de budget) ; ne rien leur attribuer.

## 2. Bonnes pratiques et seuils techniques (CWV, architecture, données structurées, SEO, GEO/agentique, accessibilité, consentement, paiement)

### Takeaway
Les seuils techniques « durs » et auditables sont : Core Web Vitals au p75 terrain (LCP ≤ 2,5 s, INP ≤ 200 ms, CLS ≤ 0,1 — 55,9 % des origines passent en sept. 2026 ; 35 à 76 % selon la plateforme e-commerce sur mobile), balisage *merchant listing* complet (Offer, shippingDetails, hasMerchantReturnPolicy, GTIN, hasCertification/EPREL), conformité EAA (applicable depuis le 28 juin 2025), bannière CNIL avec refus aussi simple que l'acceptation, et Consent Mode v2. Côté IA, Google affirme qu'aucun fichier ou balisage spécial n'est requis, tandis que les protocoles agentiques (ACP d'OpenAI/Stripe, UCP de Google) existent mais ciblent encore les États-Unis côté ChatGPT.

### Cited Findings

#### 2.1 Core Web Vitals & performance
- [V] Seuils « good » : **LCP ≤ 2,5 s ; INP ≤ 200 ms ; CLS ≤ 0,1**, évalués au **75e percentile** des chargements, segmentés mobile/desktop ; une page « passe » si les trois sont atteints (page mise à jour le 31 oct. 2024) — [web.dev, Web Vitals](https://web.dev/articles/vitals)
- [NV] Bornes « poor » usuelles : LCP > 4 s ; INP > 500 ms ; CLS > 0,25 (figurent dans les visuels de la page, non extraits en texte) — [web.dev, Web Vitals](https://web.dev/articles/vitals)
- [V] CrUX, release de septembre 2026 (publiée le 13 oct. 2026), toutes origines : **55,9 %** avec de bons CWV ; LCP bon 68,3 % ; INP bon 85,4 % ; CLS bon 81,7 %. Nouveauté : variantes expérimentales LCP/INP/CLS incluant les **soft navigations** (SPA) — 59,5 % de bons CWV avec ce mode. Aucun changement de seuil INP annoncé en 2025-2026 — [Chrome, CrUX release notes](https://developer.chrome.com/docs/crux/release-notes)
- [S] Web Almanac 2025 (chapitre Performance, CrUX juillet 2025) : 48 % des origines mobiles et 56 % des origines desktop passent les trois seuils — [HTTP Archive, Web Almanac 2025 – Performance](https://almanac.httparchive.org/en/2025/performance)
- [V] Web Almanac 2025, chapitre Ecommerce (publié le 15 janv. 2026), % d'origines avec de bons CWV **sur mobile** par plateforme : Shopify **76 %** (LCP 86 / INP 90 / CLS 92) ; Squarespace 69 % ; OpenCart 68 % ; Wix 66 % ; PrestaShop 50 % ; **WooCommerce 35 %** (LCP 39 %) ; **Magento 35 %** (LCP 52 %, CLS 64 %). Desktop : Shopify 76 %, PrestaShop 54 %, Magento 36 %, WooCommerce 33 % — [HTTP Archive, Web Almanac 2025 – Ecommerce](https://almanac.httparchive.org/en/2025/ecommerce)
- [V] Médianes Lighthouse **mobile** par plateforme (Perf / A11y / SEO / Best practices) : Shopify 55/91/92/75 ; WooCommerce 38/87/92/79 ; PrestaShop 36/79/92/79 ; Magento 34/79/92/75 ; Wix 64/95/100/79. Desktop : Shopify 71/90/92/74 ; Magento 60/78/92/74 — [HTTP Archive, Web Almanac 2025 – Ecommerce](https://almanac.httparchive.org/en/2025/ecommerce)
- [V] Parts de marché plateformes (sites e-commerce détectés, mobile) : WooCommerce 44,4 % ; Shopify 25,3 % ; Wix 11,1 % ; Squarespace 9,9 % ; PrestaShop 3,7 % ; Magento 2,2 %. Les plateformes « enterprise » (Salesforce Commerce Cloud, SAP, commercetools) ne figurent pas dans le top 10 du tableau — [HTTP Archive, Web Almanac 2025 – Ecommerce](https://almanac.httparchive.org/en/2025/ecommerce)

#### 2.2 Architecture headless / composable (MACH)
- [S, chiffres non concordants, sources secondaires citant la MACH Alliance] : 87 % des organisations auraient « largement implémenté » des technologies MACH (2025) ; 75 % des leaders retail/commerce « largement ou totalement » en composable (2026) ; 83 % de ROI positif (93 % en retail) ; 55 % citent l'amélioration de l'expérience client comme premier bénéfice — [Swell, headless commerce statistics](https://swell.is/content/headless-commerce-trends-statistics) ; [Consumer Goods Technology, MACH adoption study](https://consumergoods.com/retail-industry-leading-way-mach-adoption-study). **Sondages auto-déclarés commandités par l'alliance elle-même ; rapports primaires non consultés.**
- [V] Le chapitre Ecommerce du Web Almanac 2025 ne chiffre ni le headless ni les PWA (traités seulement qualitativement) — [HTTP Archive, Web Almanac 2025 – Ecommerce](https://almanac.httparchive.org/en/2025/ecommerce)
- [V] Point technique lié aux architectures JS/headless : Google recommande de placer le balisage produit dans le **HTML initial** ; un balisage généré en JavaScript rend le crawl « moins fréquent et moins fiable », ce qui pénalise prix/disponibilité — [Google Search Central, Merchant listing structured data](https://developers.google.com/search/docs/appearance/structured-data/merchant-listing)

#### 2.3 Données structurées (schema.org / Google merchant listings)
Source unique pour tout ce bloc : [Google Search Central, Merchant listing structured data](https://developers.google.com/search/docs/appearance/structured-data/merchant-listing) — [V].
- Éligibilité : la page doit **permettre l'achat** (une page « où acheter » renvoyant vers des revendeurs n'est pas éligible aux *merchant listings*, seulement aux *product snippets*) ; un seul produit par page ; **une URL distincte par variante** ; `Offer` unique (pas d'`AggregateOffer`) ; prix > 0 ; une URL par devise.
- `Product` — requis : `name`, `image`, `offers`. Recommandés : `aggregateRating`, `review`, `brand.name`, `description`, `gtin`/`gtin13`, `mpn`, `sku`, `color`, `material`, `size`, `category`, `hasCertification`, `isVariantOf`/`inProductGroupWithID` (`ProductGroup`), `subjectOf` (`3DModel`, glTF/GLB, un seul). Images : ratios 16:9, 4:3 et 1:1, ≥ 50 000 px.
- `Offer` — requis : `price` + `priceCurrency` (ISO 4217). Recommandés : `availability`, `itemCondition`, `priceValidUntil` (une date passée peut bloquer l'affichage), `shippingDetails`, `hasMerchantReturnPolicy`, `url`.
- Prix barré : `UnitPriceSpecification` avec `priceType: StrikethroughPrice` ; **prix à l'unité** via `referenceQuantity` (ex. prix/100 ml ou /kg) ; **prix membre** via `validForMemberTier` (`MemberProgramTier`), points fidélité `membershipPointsEarned` (bêta).
- `OfferShippingDetails` : `deliveryTime` (`handlingTime`, `transitTime` en jours), `shippingDestination.addressCountry`, `shippingRate` (0 = gratuit).
- `MerchantReturnPolicy` : `applicableCountry`, `returnPolicyCategory`, `merchantReturnDays`, `returnFees`, `returnMethod`.
- Google recommande de déclarer politiques de **retour et de livraison globales au niveau `Organization`**, le niveau produit ne servant qu'aux exceptions ; ordre de priorité : flux Merchant Center > réglages Merchant Center/Search Console > balisage produit > balisage Organization.
- Programme de fidélité : `MemberProgram`/`MemberProgramTier` sous `Organization` (ou dans Merchant Center).
- **Étiquette énergie UE** : `hasCertification` avec `issuedBy: European_Commission`, `name: EPREL`, `certificationIdentification` (code EPREL) et `certificationRating` — pertinent pour les appareils soumis à étiquette énergie.

#### 2.4 SEO technique (facettes, hreflang, canonical)
- [S, doc Google officielle vue par extraits] Navigation à facettes : deux voies — **bloquer le crawl** des URL à facettes (robots.txt, ou filtres en fragment `#`) si elles n'ont pas vocation à être indexées, **ou** les rendre efficaces : séparateur `&` standard, **ordre constant des filtres**, **404 pour les combinaisons sans résultat** ; `rel="nofollow"` n'empêche pas le crawl ; la navigation à facettes est « de loin la source la plus fréquente de sur-crawl » signalée à Google — [Google, Managing crawling of faceted navigation URLs](https://developers.google.com/crawling/docs/faceted-navigation) ; [Google Search Central blog, Crawling December: faceted navigation (déc. 2024)](https://developers.google.cn/search/blog/2024/12/crawling-december-faceted-nav)
- [S] hreflang : trois implémentations admises (balises `<link>`, en-têtes HTTP, sitemap XML) ; liens **réciproques** et auto-référents entre toutes les versions ; URL absolues ; `x-default` pour les langues/régions non couvertes ; les versions localisées ne sont des doublons que si le contenu principal reste non traduit — [Google, Tell Google about localized versions of your page](https://developers.google.com/search/docs/specialty/international/localized-versions)
- [S, sources tierces concordantes] Chaque version locale doit porter un **canonical auto-référent** (ne jamais canoniser vers une autre locale) — [scandiweb, canonicals and hreflangs for international stores](https://scandiweb.com/blog/canonicals-and-hreflangs-for-international-store/)

#### 2.5 GEO / recherche IA / commerce agentique
- [V] Google (AI Overviews / AI Mode) : pour être cité, une page doit être **indexée et éligible à un extrait** ; « There are no additional technical requirements » ; « You don't need to create new machine readable files, AI text files, or markup » ; pas de schema.org spécial. Recommandations : SEO fondamental, crawl autorisé (robots.txt **et CDN/hébergeur**), contenu important **en texte**, données structurées conformes au contenu visible, **Merchant Center à jour**. Contrôles : `nosnippet`, `data-nosnippet`, `max-snippet`, `noindex` ; `Google-Extended` pour l'entraînement/grounding hors Search. Mesure : trafic agrégé dans le rapport Performance (type « Web ») de Search Console — [Google Search Central, AI features and your website](https://developers.google.com/search/docs/appearance/ai-features)

## 3. Spécificités d'un site DTC de **marque fabricante** (vs distributeur ou DNVB)

### Takeaway
Pour un fabricant d'électroménager, le site de marque est d'abord un point de passage du parcours (32 % des acheteurs le visitent, 1,6 % seulement y achètent selon McKinsey 2023) : les experts recommandent de l'intégrer à la stratégie de canaux (assortiment distinct, services, abonnements, accessoires) plutôt que de concurrencer frontalement les distributeurs sur le prix. Le cadre réglementaire français/européen (indices de réparabilité/durabilité, droit à la réparation depuis le 31 juillet 2026, bonus réparation) fait de la réparabilité et des pièces détachées un terrain de différenciation, même si les machines à café et les ustensiles de cuisson ne sont pas soumis aux indices obligatoires.

### Cited Findings

#### 3.1 Rôle du site, conflit de canaux, prix, assortiment
- [S — rapport McKinsey d'août 2023, page inaccessible (503), chiffres lus dans des extraits] **32 % des clients visitent le site d'un fabricant d'électroménager pendant leur parcours d'achat, mais seulement 1,6 % y achètent** ; barrières à l'expansion DTC : **conflit de canaux**, capacités e-commerce sous-optimales, manque de technologie, capacités supply chain limitées ; leviers recommandés : prix et options de livraison compétitifs, **services et accessoires comme différenciateurs** ; augmenter la part DTC est une priorité à 3 ans des fabricants ; le rapport parle de « quatre facteurs clés » (détail non récupéré) — [McKinsey, Direct-to-consumer e-commerce in appliances: a strategic growth opportunity](https://www.mckinsey.com/industries/consumer-packaged-goods/our-insights/direct-to-consumer-e-commerce-in-appliances-a-strategic-growth-opportunity)
- [S] McKinsey (CPG) : la stratégie D2C ne doit pas être autonome mais intégrée à la stratégie de canaux ; le risque de conflit augmente à mesure que le site se rapproche de la vente pure ; un **assortiment distinct combiné à des services tels que l'abonnement** différencie le site D2C des sites de distributeurs — [McKinsey, Should CPG manufacturers go direct to consumer—and, if so, how?](https://www.mckinsey.com/industries/consumer-packaged-goods/our-insights/should-cpg-manufacturers-go-direct-to-consumer-and-if-so-how)

### Inferences
Dimension « spécifique marque fabricante » — critères testables proposés :
- **Clarté du modèle de vente** : chaque PDP est-elle achetable en direct, ou renvoie-t-elle vers un « où acheter » (store locator + liens e-retailers) ? Le parcours hybride est-il explicite (stock direct vs revendeurs) ?
- **Différenciation vs distributeurs** (McKinsey/BCG) : exclusivités web, bundles (machine + café/accessoires ; batteries de cuisine), personnalisation/gravure, éditions limitées, gamme complète d'accessoires et de **pièces détachées**, consommables, abonnements.
- **Politique prix** : cohérence avec les prix publics des distributeurs (pas de sous-enchère systématique), valeur ajoutée par le service plutôt que par la remise (inférence à partir de McKinsey « conflit de canaux »).
- **Captation first-party** : enregistrement produit accessible depuis la home et le compte (QR code/numéro de série), contrepartie claire (extension de garantie, contenu, offre consommables), newsletter, programme de fidélité ; création de compte post-achat.
- **Services** : espace SAV/réparation (prise en charge hors garantie, tarifs indicatifs), boutique pièces détachées recherchable par référence d'appareil, notices/tutoriels, mention du bonus réparation et de la durée de disponibilité des pièces.
- **Réparabilité/durabilité** : pour Krups (machines à café) et Lagostina (ustensiles), aucun indice obligatoire n'a été trouvé → critère = affichage **volontaire** d'engagements (durée de réparabilité, disponibilité des pièces, garantie) ; si le site vend des catégories soumises (aspirateurs, etc.), contrôler l'affichage réglementaire près du prix.
- **Avis** : volume et fraîcheur des avis, réponses de la marque aux avis négatifs, photos clients, syndication (les avis collectés sur le site de marque alimentent les distributeurs — pratique Bazaarvoice, non chiffrée ici).
- Le chiffre 32 % / 1,6 % suggère de mesurer le site de marque aussi sur son rôle d'**influence** (trafic sortant vers revendeurs, enregistrement, service), pas seulement sur sa conversion directe.

### Gaps
- Rapport McKinsey « appliances » (août 2023) non lu en primaire : les « quatre facteurs clés », la part DTC actuelle/cible et la taille de l'échantillon manquent. Donnée datée de 2023.
- Aucune étude indépendante chiffrant le taux d'enregistrement produit, la performance des widgets « where to buy » ou l'effet des exclusivités/bundles pour le petit électroménager.
- Rien trouvé de Forrester ou Bain (hors un article Bain de 2020 sur le gros électroménager, non lu) sur le DTC des biens durables en 2024-2026.
- Champ exact de l'annexe II de la directive 2024/1799 (et donc statut des machines à café/aspirateurs) non vérifié sur le texte officiel ; calendrier d'extension de l'indice de durabilité à d'autres catégories non trouvé ; sanctions pour défaut d'affichage des indices non relues.
- Engagements propres au Groupe SEB (réparabilité 15 ans, etc.) : hors périmètre de cette note.

## 4. Économie du DTC et KPI (conversion, panier moyen, CAC/LTV, réachat, rétention, part du DTC) ; modes d'échec typiques

### Takeaway
Les repères chiffrés fiables sont rares et hétérogènes : conversion « cuisine & électroménager » autour de 2,6 % en septembre 2026 sur le panel IRP (UK, en forte baisse sur un an), conversion des récurrents à 2,9 % contre 1,7 % pour les nouveaux (Contentsquare), panier moyen e-commerce français à 62 € (FEVAD 2025). La règle de viabilité la plus citée est McKinsey : CLV ≥ 2 × CAC avant passage à l'échelle ; les échecs typiques tiennent au conflit de canaux, à des coûts opérationnels et marketing supérieurs au retail et à des capacités e-commerce/tech/supply insuffisantes.

### Cited Findings
- [V] IRP Commerce, marché « Kitchen & Home Appliances », **septembre 2026** vs sept. 2025 : taux de conversion **2,59 %** (vs 3,55 %, −27 %) ; panier moyen **57,74 £** (+10,6 %) ; taux de rebond 48,73 % (vs 35,74 %) ; revenu par session 2,67 £ ; coût par session 0,20 £ (+42,6 %) ; répartition desktop 53,1 % / mobile 46,1 % / tablette 0,8 %. **Panel de marchands de la plateforme IRP (UK, taille non publiée, volatil)** — [IRP Commerce, Kitchen & Home Appliances market data](https://www.irpcommerce.com/us/en/ecommercemarketdata.aspx?Market=15)
- [S] Autres relevés IRP pour la même catégorie : 2,72 % (avril 2026) ; 2,52 % en janv. 2026 vs 3,05 % en janv. 2025 — [IRP Commerce](https://www.irpcommerce.com/us/en/ecommercemarketdata.aspx?Market=15)
- [S, agrégateurs non primaires — à ne pas citer comme référence] Conversion par appareil : desktop 3,9 %, tablette 3,1 %, mobile 1,8 % ; Europe ~3,0 % vs Amérique du Nord 3,5 % ; « kitchen appliances » 2,1 % à 2,84 % selon les sources — [Qualimero, average ecommerce conversion rate 2026](https://qualimero.com/en/blog/average-ecommerce-conversion-rate) ; [Speed Commerce, benchmarks](https://www.speedcommerce.com/insights/ecommerce-benchmarks-conversion-rates-by-industry-over-by-year/)
- [V] Contentsquare 2026 (monde, 6 000+ sites) : récurrents 2,9 % vs nouveaux 1,7 % ; desktop convertit 74 % de plus que mobile ; mobile 69,9 % du trafic ; paid search 2,8 % ; revenu +1 % malgré une conversion en baisse — [Contentsquare, DX Benchmark 2026](https://contentsquare.com/guides/digital-experience-benchmark/conversions/)

Une page mentionne un panier « stable à 68 € » (autre édition/mesure) : incohérence non résolue.
- [S] McKinsey : le modèle DTC est viable quand la **CLV vaut le double du CAC** avant le déploiement à l'échelle — [McKinsey, DTC e-commerce: How consumer brands can get it right](https://www.mckinsey.com/industries/consumer-packaged-goods/our-insights/dtc-e-commerce-how-consumer-brands-can-get-it-right)
- [S] McKinsey appliances (2023) : 32 % de visite du site fabricant vs 1,6 % d'achat ; barrières : conflit de canaux, capacités e-commerce, technologie, supply chain — [McKinsey, DTC e-commerce in appliances](https://www.mckinsey.com/industries/consumer-packaged-goods/our-insights/direct-to-consumer-e-commerce-in-appliances-a-strategic-growth-opportunity)
- [V] BCG 2021 : KPI à suivre = lifetime value, coût d'acquisition, croissance, avec KPI séparés DTC/retail mais économie partagée ; exemples (datés 2021) : Nike ~39 % des ventes en DTC (objectif 50 % en 2023) ; Peloton ~20 % du revenu en abonnements, 93 % de rétention ; acquérir une marque DTC coûte 10 à 20 fois plus que bâtir les capacités en interne ; coûts opérationnels DTC supérieurs au retail au départ — [BCG, Even Big Brands Need a DTC Strategy](https://www.bcg.com/publications/2021/direct-to-consumer-strategy-business-benefits)

- [V] Levier checkout : +35,26 % de conversion atteignable par le design du checkout (grands sites) — [Baymard, Cart Abandonment Rate](https://baymard.com/lists/cart-abandonment-rate)
- [V] Abonnements biens physiques (Recharge, voir §5) : le churn volontaire culmine à ~27 % au 3e cycle puis tombe à ~5 % au 12e — [Recharge, Subscription churn is front-loaded](https://getrecharge.com/?p=27190)

### Inferences
- Faute de benchmark public fiable « site de marque petit électroménager en France », la grille devrait noter des **pratiques observables** et réserver les KPI (conversion, AOV, réachat, CAC/LTV, NPS, part DTC) à une section « à instrumenter/à demander à la marque », avec les repères ci-dessus comme ordres de grandeur seulement.
- Ordres de grandeur prudents : conversion catégorie ~2,5-3,5 % sur des panels e-commerçants (non spécifiques aux sites de marque) ; un site de marque fabricante convertit vraisemblablement moins (indice McKinsey 32 % → 1,6 % des parcours), ce qui renforce l'importance des KPI non transactionnels (clics « où acheter », enregistrements, opt-in CRM, ventes de consommables/pièces).
- Modes d'échec typiques (synthèse McKinsey/BCG/Baymard) : (1) site vitrine sans raison d'acheter en direct (assortiment et prix identiques aux distributeurs, livraison moins bonne) ; (2) coûts d'acquisition et de logistique unitaires non couverts par la marge ; (3) frictions checkout (frais tardifs, compte obligatoire) ; (4) IT lourde et lente ; (5) gouvernance DTC/retail conflictuelle ; (6) pas de mécanique de réachat (consommables, accessoires) donc LTV faible sur un bien durable acheté rarement.
- Hausse du coût par session (+42,6 % sur le panel IRP) et baisse de conversion : la rentabilité DTC en 2026 dépend davantage de la rétention et du trafic propriétaire (CRM, SEO, base installée) que de l'acquisition payante.

### Gaps
- Aucun chiffre vérifié trouvé pour : taux de réachat, LTV/CAC observés, NPS, taux d'attachement consommables, part du DTC dans le CA des marques de petit électroménager (Groupe SEB, De'Longhi, etc.) — à chercher dans les rapports annuels (hors périmètre de cette note).
- Bilan FEVAD 2025 non lu en primaire (fevad.com) ; pas de ventilation « maison/électroménager » ni de taux de conversion FEVAD obtenus.
- Article McKinsey « DTC e-commerce: how consumer brands can get it right » inaccessible : archétypes et chiffres détaillés manquants.
- Benchmarks Dynamic Yield / Salesforce Shopping Index / Shopify par secteur et pays non consultés.
- Aucune source Gartner/Forrester publique chiffrée sur les KPI DTC.

## 5. Abonnements & consommables (subscribe-and-save, réassort, bundles)

### Takeaway
La donnée la plus solide (Recharge, 20 000+ marques, juillet 2025-mars 2026, à dominante US) montre que la résiliation est concentrée au début : ~61 % des annulations volontaires surviennent aux deux premiers renouvellements, d'où la priorité donnée au premier réassort, à la flexibilité (gestion en self-service) et à des offres de rétention adaptées au motif. En France, tout abonnement souscrit en ligne doit pouvoir être résilié en ligne via une fonctionnalité directe (« résiliation en trois clics », depuis le 1er juin 2023).

### Cited Findings
- [V] Recharge (publié juillet 2026, mis à jour août 2026 ; 20 000+ marques ; cycles de juillet 2025 à mars 2026) : churn volontaire par cycle de renouvellement : cycle 2 **24,1 %** ; cycle 3 **27,1 %** (pic) ; cycle 4 16,6 % ; cycle 5 12,4 % ; cycle 6 10,1 % ; cycle 12 5,4 % ; cycle 13+ 2,4 %. **~61 % des annulations volontaires aux deux premiers renouvellements, ~72 % dans les quatre premiers** — [Recharge, Subscription churn is front-loaded](https://getrecharge.com/?p=27190)
- [V] Par verticale (churn cycles 2-3 vs cycle 6+) : **Food & Beverage 28,2 % vs 6,4 %** ; Pets 27,8 % vs 6,5 % ; Health & Wellness 26,5 % vs 7,5 % ; Beauty 26,3 % vs 8,5 % ; **Home Goods 23,4 % vs 12,3 %** — [Recharge, Subscription churn is front-loaded](https://getrecharge.com/?p=27190)
- [V] Bonnes pratiques recommandées par Recharge : mesurer le churn **par cycle** (pas un taux mensuel moyen) ; **adapter l'offre de rétention au motif d'annulation** (cas cités : Open Farm, churn −29 % ; Wildgrain, 22 % d'annulations sauvées) ; poser les attentes et créer l'habitude dès les premières livraisons ; traiter le **premier réassort** comme le moment de rétention à plus fort levier. Limite : données descriptives, non causales ; éditeur intéressé — [Recharge, Subscription churn is front-loaded](https://getrecharge.com/?p=27190)
- [S] Churn mensuel B2C : 6,5 % (Recurly, inclut médias numériques) vs 7,1 % (panel Recharge biens physiques) ; l'effet de l'abonnement sur le panier moyen est réel pour les consommables mais ne se vérifie pas pour l'habillement ; Chewy : l'Autoship représente 83,3 % de ses 12,6 Md$ de ventes nettes — [Eightx, DTC subscription churn index 2026](https://eightx.co/blog/dtc-subscription-churn-index-2026) ; [Eightx, AOV subscription vs one-time 2026](https://eightx.co/blog/average-ecommerce-aov-subscription-vs-onetime-2026) (cabinet de conseil, secondaire)
- [S] France — « résiliation en trois clics » : décret n° 2023-417 du 31 mai 2023, en vigueur depuis le **1er juin 2023** ; le professionnel doit offrir une **fonctionnalité de résiliation en ligne gratuite, directement et facilement accessible** depuis l'interface (site/app), pour les contrats pouvant être souscrits en ligne ; sanctions DGCCRF évoquées jusqu'à 75 000 € (non vérifié sur texte) — [Deloitte Société d'Avocats, la résiliation en 3 clics](https://blog.avocats.deloitte.fr/la-resiliation-en-3-clics-nouvel-outil-au-service-des-consommateurs/?amp=1) ; [INC, résilier votre contrat d'abonnement en quelques clics](https://www.inc-conso.fr/content/vous-pouvez-resilier-votre-contrat-dabonnement-en-quelques-clics)
- [V] UX consommables : 81 % des sites n'affichent pas le prix à l'unité sur la PDP pour les lots/multi-formats, 67 % en liste — [Baymard, Product Page UX](https://baymard.com/blog/current-state-ecommerce-product-page-ux) ; [Baymard, Product List UX](https://baymard.com/blog/current-state-product-list-and-filtering)
- [V] Données structurées : prix à l'unité (`referenceQuantity`) et prix membre/abonné (`validForMemberTier`) supportés par Google — [Google, Merchant listing structured data](https://developers.google.com/search/docs/appearance/structured-data/merchant-listing)
- [S] McKinsey : assortiment distinct + abonnement = différenciation du site D2C face aux distributeurs — [McKinsey, Should CPG manufacturers go direct to consumer](https://www.mckinsey.com/industries/consumer-packaged-goods/our-insights/should-cpg-manufacturers-go-direct-to-consumer-and-if-so-how)

### Inferences
Critères testables proposés pour la grille (café/Krups en priorité ; faible pertinence pour le cookware) :
- Présence d'une offre de consommables compatible par machine (grains, capsules, détartrant, filtres, produits d'entretien) et **compatibilité recherchable par modèle**.
- Option « s'abonner et économiser » sur la PDP consommable : remise affichée, fréquence modifiable, mention explicite « sans engagement », prix à l'unité (€/kg, €/tasse).
- Espace abonné en self-service : sauter/décaler une livraison, changer de produit, pause, **résiliation en ligne directe** (conformité « trois clics »).
- Rappel avant chaque prélèvement/expédition ; onboarding des 2-3 premières livraisons (là où se concentrent 61 % des résiliations).
- Flux de rétention à l'annulation fondé sur le motif (trop de stock → décalage ; prix → offre ; goût → échange).
- Bundles machine + consommables (kit de démarrage) et réassort déclenché par l'enregistrement produit (rappel de détartrage, changement de filtre).
- Indicateurs à demander : taux d'attachement consommables par machine vendue/enregistrée, churn par cycle, part du CA récurrent.

### Gaps
- Aucune donnée chiffrée fiable sur la profondeur de remise optimale, l'effet des fonctions pause/skip/swap, ni la LTV abonnés vs non-abonnés (les chiffres trouvés viennent d'agrégateurs sans source primaire).
- Rapport complet Recharge 2026 non consulté ; données à dominante US ; pas de benchmark européen/français de l'abonnement café.
- Pas de données spécifiques café (Nespresso, De'Longhi, L'OR, torréfacteurs DNVB) dans cette note — à couvrir par les notes concurrentielles.
- Texte du décret 2023-417 et articles du Code de la consommation non relus en primaire ; une révision du dispositif évoquée au Sénat n'a pas été confirmée.

## 6. Scorecards / cadres d'audit DTC existants pouvant inspirer la grille (dimensions, pondérations)

### Takeaway
Le seul cadre public suffisamment granulaire est celui de Baymard (thèmes par étape du parcours, centaines de guidelines notées site par site sur une échelle allant de « poor » à « perfect »), complété par les quatre scores Lighthouse pour la technique et les six capacités BCG pour la maturité organisationnelle ; la méthodologie Gartner Digital IQ est sous paywall et ses pondérations n'ont pas pu être vérifiées. Aucune grille publique dédiée aux sites DTC de marques fabricantes de biens durables n'a été trouvée : la grille devra être composée.

### Cited Findings
- [V] Baymard — structure du benchmark : thèmes par étape (Homepage & Category Navigation ; On-site Search ; Product Lists & Filtering ; Product Page ; Cart & Checkout…), chaque thème découpé en sous-thèmes (ex. PDP : 12 sujets de 4 à 21 guidelines, 115+ guidelines), chaque site noté guideline par guideline puis classé (« perfect », « good », « decent », « mediocre », « poor », « very poor ») ; desktop, mobile et app notés séparément — [Baymard, Product Page UX](https://baymard.com/blog/current-state-ecommerce-product-page-ux) ; [Baymard, Checkout UX 2026](https://baymard.com/blog/current-state-of-checkout-ux)

- [S] Baymard publie aussi des benchmarks sectoriels (ex. « Mass Merchant UX benchmark 2026 », 22 oct. 2026 ; 5 600+ scores) et un classement de 344 sites — [Baymard, Mass Merchant UX Benchmark 2026](https://baymard.com/research-articles/mass-merchant-ux-benchmark-2026) ; [Baymard, UX benchmark](https://baymard.com/ux-benchmark/guideline-collections/xpjddi)

|---|---|---|---|---|
